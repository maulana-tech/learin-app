# STAT 101 Introductory Statistics: Syllabus

Northbridge University · Fall 2026 · 3 credits
Lecturer: Dr. M. Okafor · Lectures Mon/Wed 13:00–14:30, Room A1.02

## Course description
Describing data, probability, sampling distributions, confidence intervals and hypothesis testing,
with an emphasis on interpreting results correctly rather than on computation.

## Learning outcomes
1. State null and alternative hypotheses for a research question.
2. Explain what a p-value is and what it is not.
3. Distinguish Type I and Type II errors and relate them to the significance level.
4. Report a test result in one honest sentence.
