# STAT 101 Problem Set 3: Hypothesis Testing

**Due: Wednesday 25 November 2026, 17:00** · Individual · 15% of the course grade
Submit one PDF. Show your reasoning; a bare number earns no marks.

## Questions
1. **Coffee and exam scores.** A student claims that drinking coffee before an exam raises scores.
   Write the null and alternative hypotheses in words and in symbols.
2. **What a p-value means.** A study reports p = 0.03. Which of these statements are correct? Explain each.
   (a) There is a 3% chance the null hypothesis is true.
   (b) If the null hypothesis were true, data at least this extreme would occur about 3% of the time.
   (c) The effect is large.
3. **Errors.** In a test of a new medicine, describe a Type I error and a Type II error in plain words.
   Which one is worse here, and how would that change your choice of significance level?
4. **Reporting.** Rewrite this sentence so it says only what the test shows:
   "The test proved that the new teaching method works."
5. **Short essay (max 200 words).** Why do statisticians warn against treating p < 0.05 as a yes/no answer?
   Support every claim with the course reading.

## Marking
Questions 1–4: 15 marks each. Question 5: 40 marks, of which 15 are for claims supported by the reading.
