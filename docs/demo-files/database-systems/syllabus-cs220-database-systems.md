# CS 220 Database Systems: Syllabus

Northbridge University · Fall 2026 · 3 credits
Lecturer: Dr. A. Rivera · Lectures Tue/Thu 10:00–11:30, Room B2.14

## Course description
How relational databases are designed and queried: the relational model, entity–relationship modelling,
functional dependencies and normalisation (1NF to BCNF), SQL (selection, joins, aggregation, subqueries),
indexing and transactions.

## Learning outcomes
By the end of the course you can:
1. Model a real system as an entity–relationship diagram.
2. Normalise a schema to third normal form and explain each step with functional dependencies.
3. Write SQL queries that combine tables with inner and outer joins.
4. Explain why a design choice trades redundancy against query cost.
