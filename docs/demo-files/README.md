# LEARIS demo course pack

Four courses at a fictional university (Northbridge University, Fall 2026) for recording the demo video.
See [`../demo-video.md`](../demo-video.md) for the storyline.

| Course | Files |
|---|---|
| **Database Systems** (CS 220) | syllabus, group project brief, readings on normalisation and SQL joins |
| **Introductory Statistics** (STAT 101) | syllabus, Problem Set 3 brief, reading on hypothesis testing |
| **Principles of Microeconomics** (ECON 110) | syllabus, policy essay brief, reading on price elasticity |
| **Introduction to Psychology** (PSY 100) | syllabus, lab report brief, reading on classical conditioning |

## How to use
1. In **Files**, upload each folder and set its course to the course name above.
2. In the **Assistant**, ask:
   *Summarise each course in Files, one page per course, and put every deadline on the board.*
3. **Tasks** should then show these nine deadlines:

| Date (2026) | Course | Item |
|---|---|---|
| Wed 25 Nov, 17:00 | STAT 101 | Problem Set 3 |
| Fri 27 Nov, 23:59 | CS 220 | Project milestone 1 (ERD) |
| Thu 3 Dec, 23:59 | PSY 100 | Lab report |
| Mon 7 Dec, 12:00 | ECON 110 | Policy essay |
| Fri 11 Dec, 23:59 | CS 220 | Project final report and SQL |
| Tue 15 Dec, 09:00 | CS 220 | Final exam |
| Wed 16 Dec, 13:00 | STAT 101 | Final exam |
| Thu 17 Dec, 09:00 | ECON 110 | Final exam |
| Fri 18 Dec, 10:00 | PSY 100 | Final exam |

4. **Claim check scene.** None of the readings says 3NF makes queries faster. Ask the Assistant:
   *Add to the Database Systems page: "Tables in third normal form always make queries faster."*
   Then press **Check claims**: that sentence is flagged as unsupported, and the Claim Auditor rewrites it.
   In the narration, say that it was added on purpose to test the check.
