# Resepku — berbagi resep rumahan

Proyek pribadi: aplikasi web untuk menyimpan dan berbagi resep.

## Fitur
- Daftar, cari, dan simpan resep favorit
- Upload foto resep
- Login dengan email

## Teknologi
- React (hooks: useState, useEffect) untuk antarmuka
- Tailwind CSS untuk styling, layout responsive
- Firebase Firestore untuk data, Firebase Authentication untuk login
- Deployed di Vercel

## Menjalankan
```
npm install
npm run dev
```

Kode dikelola dengan Git; setiap fitur dikerjakan di branch terpisah lalu digabung lewat pull request.
